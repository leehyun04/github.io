📖 인터넷 클리너 : 완벽 청소 공략 가이드

웹 클리너(Web Cleaner)는 복잡하고 어지러운 포털 사이트 화면의 모든 버튼을 하나씩 눌러 지워나가면서, 무작위로 숨겨진 '꽝(지뢰)'을 피해 화면을 100% 순백으로 청소하는 고도의 심리전 & 반응속도 게임입니다.

🎮 게임 기본 규칙 및 플레이 방법

  • 조작 방법: 마우스 좌클릭 또는 스마트폰 화면 터치로 원하는 요소를 누릅니다.
  • 클리어 조건: 화면에 존재하는 모든 안전한 버튼을 꽝 없이 전부 누르면 승리합니다.
  • 패배 조건: 꽝(지뢰)이 숨겨진 버튼을 누르면 비상 사이렌과 함께 즉시 게임 오버됩니다.
  • 콤보 시스템: 연속으로 빠르게 안전 버튼을 누르면 콤보 점수가 오르고 경쾌한 도-레-미-파 음계 상승 사운드가 재생됩니다.

⚡ 특수 아이템 활용 전략

게임을 진행하다 보면 특정 안전 버튼에서 강력한 서포트 아이템이 무작위로 등장합니다:

  • 🔍 돋보기 아이템: 아직 누르지 않은 안전한 버튼 1개를 황금빛으로 3초간 깜빡여 알려줍니다. 발견 즉시 눌러주세요!
  • 💉 백신 쉴드 아이템: 꽝을 밟아도 1회에 한해 게임 오버를 막아주는 방어막을 획득합니다. 후반부 심리전에 매우 유용합니다.

🏆 고득점 & 최단 시간 클리어 팁

  1. 외곽부터 차례대로 공략하기: 상단 로고나 하단 푸터 링크처럼 시각적으로 눈에 잘 띄는 영역부터 청소해 나가면 남은 버튼 위치를 파악하기 쉽습니다.
  2. 남은 버튼 3개 이하의 심장박동 구간: 안전 버튼이 3개 이하로 남으면 긴장감 심장박동 사운드가 재생됩니다. 이때 서두르지 말고 침착하게 남은 안전 버튼을 선택하세요.
  3. 무한 챌린지 모드: 1층을 클리어할 때마다 버튼 수와 꽝의 개수가 늘어납니다. 연속으로 몇 층까지 도달할 수 있는지 도전해 보세요!

📜 최근 플레이 기록

ℹ️ 사이트 소개 (About Web Cleaner)

웹 클리너(Web Cleaner)는 일상에서 매일 접하는 인터넷 포털 웹사이트를 유쾌하게 재해석한 HTML5 기반 캐주얼 인터랙티브 웹 게임입니다.

💡 기획 배경 및 철학

수많은 정보와 배너, 광고로 가득 찬 현대의 복잡한 웹페이지를 하나씩 '청소'해 나가며 얻는 시각적 카타르시스와, 단 한 번의 실수로 터지는 '꽝'의 쫄깃한 긴장감을 결합하여 누구나 설치 없이 브라우저에서 바로 즐길 수 있는 미니멀한 엔터테인먼트를 제공합니다.

🛠️ 기술적 특징

  • 무설치 & 즉시 실행: 별도의 앱 설치나 플러그인 없이 데스크톱과 모바일 브라우저에서 60fps로 매끄럽게 동작합니다.
  • Web Audio API 사운드 합성: 외장 음원 파일 다운로드 지연 없이 브라우저 내장 오실레이터로 고품질 타격음과 멜로디를 합성하여 0.01초의 딜레이도 없는 찰진 손맛을 선사합니다.
  • 개인정보 비수집: 플레이어의 모든 점수와 통계는 오직 사용자의 브라우저 로컬 저장소(LocalStorage)에만 안전하게 보관됩니다.

🔒 개인정보처리방침 (Privacy Policy)

본 사이트(이하 "웹 클리너")는 사용자의 개인정보를 매우 소중하게 생각하며, 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목

본 사이트는 회원가입이나 개인 식별 정보(이름, 주민등록번호, 연락처 등)를 요구하거나 서버에 수집하지 않습니다. 게임 진행 상황 및 최고 점수는 전적으로 이용자의 웹 브라우저 로컬 저장소(LocalStorage)에만 기록됩니다.

2. 쿠키(Cookie) 및 제3자 광고 (Google AdSense) 관련 고지

본 웹사이트는 트래픽 분석 및 맞춤형 광고 게재를 위해 Google 등 제3자 제공업체의 서비스를 이용할 수 있습니다:

  • Google을 포함한 제3자 광고 제공업체는 쿠키를 사용하여 이용자의 본 사이트 및 다른 웹사이트 방문 기록을 바탕으로 광고를 게재합니다.
  • Google의 DART 쿠키 사용을 통해 Google과 파트너는 인터넷 방문 기록을 바탕으로 맞춤형 광고를 제공할 수 있습니다.
  • 사용자는 Google 광고 설정을 방문하여 맞춤형 광고에 사용되는 쿠키를 비활성화할 수 있습니다.

3. 로그 데이터

웹 서버는 사이트 안정성 유지와 보안을 위해 표준적인 접속 로그(접속 IP 주소, 브라우저 유형, 방문 시간 등)를 일시적으로 기록할 수 있으며, 이는 통계 목적으로만 활용됩니다.
